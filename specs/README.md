# Project decisions

`specs/` contains the project's current decisions only.

- [Roadmap](roadmap.md) states the current path to 1.0.
- [Proposals](proposals/) contain the active work that can change that path.

Completed implementation diaries, plans, audits, and evidence records are
removed from the working tree. They remain available through Git history.
Published and runtime claims belong in tests, `benchmarks/`, `docs/`, and the
`CHANGELOG`.
