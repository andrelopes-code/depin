# Security Policy

## Supported versions

Security fixes are provided for the following versions of `pydepin`:

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

While the project is pre-1.0, only the latest minor series receives security
fixes. Older series are not backported.

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Do not open a public
issue, pull request, or discussion for a suspected vulnerability.

Use either of the following channels:

- **GitHub Security Advisories** (preferred):
  <https://github.com/andrelopes-code/depin/security/advisories/new>
- **Email:** andrelopes.code@gmail.com

Please include enough detail to reproduce the issue: affected version, a
minimal proof of concept, and the impact you observed.

## Response process

- We will acknowledge your report within **72 hours**.
- After acknowledgement, we will assess the report and communicate a fix
  target and a coordinated disclosure timeline.
- We will keep you informed of progress and credit you in the advisory once a
  fix is released, unless you prefer to remain anonymous.
